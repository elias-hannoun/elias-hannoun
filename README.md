## 💫 About Me

I am a Software Developer and a recent Software Engineering graduate from Concordia University. I have a passion for building software that solves complex, real-world problems. My experience ranges from full-stack development and machine learning to data-driven systems, with a professional background that includes software development, aerospace flight physics and IT infrastructure management.   

- 🚀 **Currently building:** [Musiqa](https://musiqa.eliashannoun.com/), a music notation and chord management platform, and GazRadar (more info coming soon!).
- ⚙️ **Recent focus:** Exploring advanced mobile development (Kotlin/Jetpack Compose, React Native) and cybersecurity concepts.
- 🎨 **Beyond the screen:** I enjoy graphic design, exploring digital branding, and playing the guitar.
